# 🧾 Living Code for JSON / JavaScript

**Calm slate. Living color.** Living Code for JSON / JavaScript. Repository-owned theme files, installation instructions and four color flavors.

[Installation](#installation) · [Flavors](#flavors) · [Configuration](#configuration) · [All ports](https://github.com/living-code-theme)

## Previews

Real application screenshots have not been captured yet.

## Installation

```sh
pnpm add @living-code/palette
```

```js
import { palette } from "@living-code/palette";
palette.night.colors.teal.hex;
palette.night.roles.keyword;
```

Or read `palette.json` from any language.

## Configuration

See [JSON / JavaScript's documentation](https://github.com/living-code-theme/palette) for application settings and reload behavior. The activation instructions above identify each supported flavor; keep your other application configuration.

## Compatibility

Preserves the npm package name `@living-code/palette` and its existing import paths. Package publication and registry credentials are separate from creating this repository.
